Built for the desktop

Organizer is a real Windows app, so it can do things a website can't:

  • 🛡 Automatic backups: every change is saved as a file in Documents/Organizer-Backups, with one snapshot per day kept for 30 days.
  • ⏰ Reminders in the background: appointments and deadlines show up as Windows notifications even when the window is closed.
  • 📌 System tray & autostart: closing the window keeps Organizer running in the tray, and it can start together with Windows if you like.
  • 📁 Files: browse, preview and open files from your Documents, Downloads, Pictures and more right inside the app.
  • 🖥 Screen time: see which programs you spend your time in, next to a time clock and productivity stats.
  • 🪟 Pop-out windows: detach any module into its own window, keep it always on top and adjust its opacity.
  • 🌤 Weather: current weather and forecast for your city.

Your data stays yours

No account, no cloud and no tracking. Organizer stores everything locally on your computer.

WhatHow it's handled
Your tasks, notes, events etc.Saved only on your computer. Nothing is uploaded and there is no Organizer server.
BackupsPlain JSON files in your Documents folder. You can export everything and import it again at any time (Settings → Export all / Import).
Analytics / telemetryNone. The app does not collect or send usage data.
AI assistant (optional)Only active if you add your own Claude or OpenAI API key. The key is encrypted by Windows, and your questions go directly to the provider you chose.
Online extras (optional)Weather (Open-Meteo), maps (OpenStreetMap) and stock quotes only contact those services when you use them.
UninstallingYour data is kept when you uninstall, so you can reinstall without losing anything.

Install in a minute

  1. Download Organizer-Setup.exe.
  2. Run it. Windows may show “Windows protected your PC” because the app isn't code-signed yet (signing certificates are expensive for a hobby project). Click More info → Run anyway.
  3. Choose a folder (or keep the default). The installer creates a desktop shortcut and a Start menu entry.
  4. Pick a language and a profile, and you're ready to go.

Requirements: Windows 10 or 11, 64-bit, about 300 MB of free disk space. A macOS version may follow later.

FAQ

Is Organizer free?

Yes, the beta is completely free.

Do I need an internet connection?

No. Everything works offline. Only optional extras like weather, maps, stock quotes or the AI assistant need a connection.

Can I sync between two PCs?

There's no built-in cloud sync yet. You can export your data on one PC and import it on another, or keep the backup folder inside OneDrive.

Will my data survive updates?

Yes. Updates replace only the app itself, not your data. To be safe during the beta, export a backup now and then.
